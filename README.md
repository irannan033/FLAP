# Factory Logistics Automation Project - FLAP

## Overview

An industrial logistics automation project implementing
AGVs for automated material transportation in garment
manufacturing.

## Objectives

- Automate material transportation
- Reduce manual trolley movement
- Improve material flow
- Reduce transportation-related delays
- Improve logistics traceability
- Real time garments/ material tracking

## My Responsibilities

- Designed and configured AGV routes for material transportation.
- Prepared and optimized RCS maps.
- Configured transportation workflows.
- Integrated AGV operations with factory logistics systems.
- Troubleshot AGV, network and PLC-related issues.
- Monitored system alarms and operational performance.
- Supported production deployment and commissioning.
